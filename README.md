# Οικοδομή — web build

Αυτό το repository περιέχει **μόνο το μεταγλωττισμένο build** της PWA
«Οικοδομή», ώστε να σερβίρεται από το GitHub Pages.

**Ζωντανή εφαρμογή:** https://tmartsoukos.github.io/oikodomi-web/

Στο κινητό: άνοιξε τον σύνδεσμο και πάτησε «Προσθήκη στην αρχική οθόνη».
Η εφαρμογή ανοίγει fullscreen, σαν κανονική εφαρμογή, και λειτουργεί
και χωρίς σήμα.

## Πώς ενημερώνεται

**Αυτόματα.** Κάθε push στο `main` του ιδιωτικού repository `oikodomi` τρέχει
το workflow `Deploy PWA`, που χτίζει τη web έκδοση και κάνει force push εδώ.

Μην επεξεργάζεσαι τα αρχεία αυτού του repository — χάνονται στο επόμενο deploy.
Το ιστορικό κρατά μόνο το τελευταίο build.

## Σημειώσεις

- Το κλειδί του Supabase μέσα στο bundle είναι το *publishable* (anon) κλειδί,
  το οποίο προορίζεται να είναι ορατό στον client. Η πρόσβαση στα δεδομένα
  ελέγχεται από τα Row Level Security policies της βάσης: κάθε χρήστης βλέπει
  μόνο τις δικές του εγγραφές.
- Το `.nojekyll` είναι απαραίτητο: χωρίς αυτό το GitHub Pages αγνοεί τον φάκελο
  `_expo/` (το Jekyll παραλείπει ό,τι ξεκινά με κάτω παύλα) και η εφαρμογή δεν
  φορτώνει.
